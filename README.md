# Бейнені тану негізінде адамның қозғалысындағы қауіпті жағдайларды анықтайтын автоматты интеллектуалды жүйе

OpenCV және MediaPipe/YOLO Pose негізінде адамның құлауы мен қауіпті қозғалыстарын (тепе-теңдіктің бұзылуы, кенеттен тоқтау) нақты уақыт режимінде анықтап, Telegram Bot арқылы дереу хабарлама жіберетін интеллектуалды жүйе.

## Жобаның мақсаты

Бейне деректер негізінде адамның қозғалысын талдау және қауіпті жағдайларды (құлау, қозғалыстың тоқтауы, тепе-теңдіктің бұзылуы) автоматты түрде анықтайтын интеллектуалды жүйе әзірлеу. Жүйе әсіресе жалғыз тұратын немесе қарт жастағы адамдар үшін, аурухана мен қарттар үйлерінде, сондай-ақ өндірістік нысандарда қауіпсіздікті қамтамасыз ету мақсатында қолданылуы мүмкін.

## Қолданылған технологиялар

- **Python** — негізгі бағдарламалау тілі
- **OpenCV** — бейнені өңдеу және кадрларды талдау
- **MediaPipe** — адамның дене қимылын (pose) нақты уақытта тану
- **YOLO Pose (Ultralytics)** — адамның қалпын анықтау және қозғалысты бақылау
- **Telegram Bot API** — қауіпті жағдай анықталғанда хабарлама жіберу

## Орнату

1. Репозиторийді өз компьютеріңе клондаңыз:
```bash
git clone https://github.com/nadirkhangulnaz-collab/my-project.git
cd my-project
```

2. Қажетті кітапханаларды орнатыңыз:
```bash
pip install -r requirements.txt
```

3. Telegram Bot токенін баптаңыз (өз ботыңызды [@BotFather](https://t.me/BotFather) арқылы жасап, токенді код ішінде немесе орта айнымалысында көрсетіңіз).

## Іске қосу

```bash
python Isakova_project.py
```

Бағдарлама компьютердің камерасын немесе бейнефайлды өңдеп, адамның қозғалысын нақты уақытта талдайды. Қауіпті жағдай (мысалы, құлау) анықталған жағдайда, жүйе автоматты түрде Telegram арқылы хабарлама жібереді.
